# Kanya Portfolio Template

One-page responsive portfolio in a modern black-and-pink visual style. Built with plain HTML, CSS, and JavaScript; no build step is required.

The included `.gitignore` prevents operating-system clutter, editor settings, logs, temporary files, local environment files, and future dependency/build folders from being committed. It does not ignore `index.html`, `styles.css`, or `script.js`, so GitHub Pages can publish the website normally.

## Edit before publishing

1. Replace `your.email@example.com` in `index.html`.
2. Replace the `#` links for LinkedIn and Facebook.
3. Update the About, Expertise, and Selected Work content to match your final profile.

## Run locally

Open `index.html` directly, or serve the folder with any static web server.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The site is static and works without npm or a build command.
